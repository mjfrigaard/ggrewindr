# ggrewindr 0.2.0

* Every theme now uses open source fonts that ship with the package, so the themes look the same on macOS, Windows, and Linux. The macOS system fonts are replaced with Google Fonts under the SIL Open Font License or the Apache License (for example, Arial becomes Arimo, Herculanum becomes Macondo, and DIN Condensed becomes Barlow Condensed). Each font's license sits next to it in `assets/`.

# ggrewindr 0.1.0

* First release. The 47 late 90s themes and the bundled Press Start 2P font move here from `fmggp2` 0.71.0, which replaced them with Gen Z themes in 1.0.0.
